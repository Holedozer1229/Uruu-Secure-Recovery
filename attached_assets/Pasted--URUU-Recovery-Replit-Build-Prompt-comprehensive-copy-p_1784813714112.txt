### 3) Features, API contract, and user flows (must implement)

#### Core flows (implement exactly)
1. **InitiateRecovery** (owner)  
   - Frontend form: `NewPublicKey` (public), `RequestedTimelock`, optional metadata.  
   - Backend: create `RequestId = H(initiator||newKeyCommit||timestamp)`, store `RecoveryRequest` state `INITIATED`, emit `RecoveryInitiated` event.

2. **Generate & Submit Proof** (owner → verifier → on‑chain)  
   - Frontend: upload `proofBlob` (synthetic) and `publicInputs` (AccountID, RequestId, NewKeyCommit, PolicyCommit, ProofNonce).  
   - Verifier service: **mock verify** the proofBlob against publicInputs, compute `proofHash = SHA256(proofBlob)`, sign canonical `SignInput` and return `ProofReceipt`.  
   - Backend: `submitProofReceipt` endpoint verifies `verifierSig`, checks `proofHash` not reused, stores `proofHash`, sets state `PROOF_SUBMITTED`, emits `ProofSubmitted`.

3. **Guardian Approval** (guardian)  
   - Guardian dashboard lists pending `ProofSubmitted` requests. Guardian verifies receipt off‑chain (mock) and submits `GuardianApproval` (signed).  
   - Backend verifies guardian signature, increments approvals, if `approvals >= quorum` set state `APPROVED`, emit `GuardianApproved`.

4. **Timelock & Contest**  
   - Backend enforces `T_lock` (configurable). Monitors can submit `Contest` with `contestHash` (off‑chain evidence reference). If contested, set state `CONTESTED`.

5. **FinalizeRecovery**  
   - After timelock and if approvals ≥ quorum and no unresolved contest, backend binds `NewKeyCommit` to account mapping and sets state `FINALIZED`, emit `RecoveryFinalized`.

6. **Audit & Event Log**  
   - All events appended to JSONL log and broadcast via WebSocket. Provide UI to download event log and view ProofReceipts and GuardianApprovals.

#### API endpoints (TypeScript signatures)
- `POST /api/recovery/initiate` → `{ newKeyCommit, policyCommit, requestedTimelock }` → returns `{ requestId }`
- `POST /api/recovery/:requestId/submit-proof` → `{ proofReceipt }` → validates verifierSig
- `POST /api/recovery/:requestId/guardian-approve` → `{ guardianApproval }` → validates guardianSig
- `POST /api/recovery/:requestId/contest` → `{ contestHash }`
- `POST /api/recovery/:requestId/finalize` → no body; enforces timelock & quorum
- `GET /api/recovery/:requestId` → returns request state and metadata
- `GET /api/events` → returns event log (paginated)
- `WS /events` → real‑time event stream
